# 🐘 Smart Elephant

Smart Elephant is a multilingual AI-powered educational platform designed to help preschool children develop speech, language, and cognitive skills through interactive games.

## Vision

Build a production-quality EdTech platform while learning modern Full Stack development.

## Tech Stack

### Frontend

- React
- TypeScript
- Vite
- React Router
- Tailwind CSS

### Backend

- Java
- Spring Boot
- PostgreSQL

### Future

- Redis
- Kafka
- Docker
- AWS
- Kubernetes

frontend/
backend/

Frontend

Backend
