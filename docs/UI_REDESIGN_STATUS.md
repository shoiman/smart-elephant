# UI Redesign "Premium Scandinavian" — статус (2026-10-13, конец дня)

Референс: 8 экранов (главная, категории, «Кто это?», правильно, где живёт, что ест, награда, каталог) — картинка от Наты. MagicPath не используем — работаем по картинке. Каждый этап согласуется с Натой.

## Решения
- Ведущий — слонёнок. Позы: `assets/characters/elephant-greeting.png` (машет: главная, аватар в панели вопроса, «Почти!», загрузка) и `elephant-happy.png` (радуется: «Правильно!», награда). Компонент `Host` с prop `pose`.
- Голос: Web Speech API (`hooks/useSpeechRecognition.ts`), текст → существующий POST /games/answer; fallback — поле ввода. Тишина = неудачная попытка; после 3 неудач — «Давай скажем вместе».
- Категории: только фильтр каталога по habitat (backend не фильтрует вопросы).
- Шрифты: Nunito (заголовки) + Rubik (текст, иврит).
- Шапка: назад / по центру бренд или прогресс (5 сегментов) / язык «RU ⌄» (выпадающее меню). Без «бургера» — меню не существует.
- Главная: слонёнок и облачко в разных колонках грида — не пересекаются (Ната просила). Облачко маленькое, max 200px.

## Исправлено 2026-10-13 (прод)
- 403 на POST /api/* после перехода на HTTPS: Spring CORS разрешает только localhost, а браузер шлёт Origin https://…sslip.io. Фикс в `frontend/Caddyfile`: `reverse_proxy backend:8080 { header_up -Origin }` (API same-origin). Caddyfile зашит в образ → деплой только с `--build`.
- `QuestionService.getNextQuestion` теперь `{ cache: false }` — раньше http-client кэшировал GET и отдавал один и тот же вопрос сутки.
