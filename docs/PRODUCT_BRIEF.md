# PRODUCT_BRIEF — Smart Elephant

**Smart Elephant** — веб-платформа (PWA) для развития речи и логики у детей 2–6 лет, на старте 2–4 года. Ведущий — слонёнок. Языки: иврит, русский, украинский. Игр для развития речи на иврите почти нет — это главное отличие.

## Для кого
Дети 2–6 лет, в том числе с особенностями речевого развития. Покупатель — родитель. Позже — садики и логопеды.

## Как работает игра (мир «Животные»)
- Слонёнок показывает животное и задаёт вопрос голосом: кто это, какого цвета, где живёт, что ест, большой или маленький, как говорит, сколько ног, что в нём необычного.
- Ребёнок отвечает голосом в микрофон. Разрешение на микрофон один раз даёт родитель.
- Неправильно или тишина — максимум 2 попытки. После первой — ободрение («подумай ещё»), на уровне «старший» появляются картинки-подсказки. После второй — «давай скажем вместе», ответ звучит, игра идёт дальше.
- Картинки-варианты ответа (где живёт, что ест, какого цвета) зависят от уровня: малыш — 2 картинки, можно нажать; средний — 4 картинки-подсказки, ответ голосом; старший — картинки только после первой ошибки.
- Все вопросы про животное пройдены — звезда и похвала.
- Сложность адаптивная: по доле правильных ответов за последние игры (меньше 50% — легко, 50–80% — средне, больше 80% — сложно).

## Что уже есть
- Фронтенд: React 19 + TypeScript + Vite, дизайн «Premium Scandinavian», 3 языка, RTL.
- Бэкенд: Java 21, Spring Boot 3, PostgreSQL, Flyway.
- Проверка ответов: правила и синонимы (AnswerChecker), без LLM.
- Озвучка: Azure AI Speech, кэш mp3. Распознавание речи: Web Speech API браузера.
- Хостинг: Hetzner, Docker Compose, Caddy, HTTPS.
- 48 животных; картинки-варианты ответа (23 иконки места и еды, цвета кружками).

## Планы
Другие миры: действия (бежит, сидит, идёт), счёт (найди и посчитай животных в сцене). Claude API — для ответов, которые не распознали правила. Приложение через PWA.

## Принципы
- Ребёнок играет без чтения: всё голосом и картинками.
- Никакого давления и наказаний за ошибки.
- Данные детей — минимум. Голос уходит третьей стороне (Google/Apple при распознавании), это раскрывается в политике приватности.
